# Ship Files

> **Note:** results are a learning aid, not a professional audit or legal advice.

Adds the pages and repo files a real site needs: privacy, terms, about, contact, 404, footer, README, .gitignore, .env.example, LICENSE. Use before shipping.

**Best in a coding tool.** The main version is `claude/SKILL.md`: run it in Claude Code or Gemini CLI with your project open, and it reads your code, rules, and planning files itself, so it asks only a question or two. `chatgpt.md` and `prompt.md` are a short fallback for any AI chat, where you share your live link and code or screenshots.

| File | Use it with |
| --- | --- |
| [claude/SKILL.md](claude/SKILL.md) | Claude Code (copy the contents of `claude/` into `~/.claude/skills/ship-files/`) |
| [claude/SKILL.md](claude/SKILL.md) | Gemini CLI (copy the contents of `claude/` into `~/.gemini/skills/ship-files/`; [setup guide](../../README.md#gemini-cli)) |
| [../../dist/ship-files.zip](../../dist/ship-files.zip) | Claude.ai (upload in your skills settings) |
| [chatgpt.md](chatgpt.md) | A ChatGPT Project |
| [prompt.md](prompt.md) | Gemini Gem (paste the text inside the box into saved Gem instructions; [setup guide](../../README.md#gemini-web-app-gems)) |
| [prompt.md](prompt.md) | Any AI, pasted into a chat |
