# Privacy Check

> **Note:** results are a learning aid, not a professional audit or legal advice.

Educational privacy and data check of your own site: policy, consent, data collected, user control, GDPR and CCPA basics. Not legal advice. Use before launch.

**Best in a coding tool.** The main version is `claude/SKILL.md`: run it in Claude Code or Gemini CLI with your project open, and it reads your code, rules, and planning files itself, so it asks only a question or two. `chatgpt.md` and `prompt.md` are a short fallback for any AI chat, where you share your live link and code or screenshots.

| File | Use it with |
| --- | --- |
| [claude/SKILL.md](claude/SKILL.md) | Claude Code (copy the contents of `claude/` into `~/.claude/skills/privacy-check/`) |
| [claude/SKILL.md](claude/SKILL.md) | Gemini CLI (copy the contents of `claude/` into `~/.gemini/skills/privacy-check/`; [setup guide](../../README.md#gemini-cli)) |
