# PRD Architect

Interviews you one question at a time and co-writes a PRD (product plan) to hand to any AI coding tool. Use when planning a new app, feature, or MVP before building.

| File | Use it with |
| --- | --- |
| [claude/SKILL.md](claude/SKILL.md) | Claude Code (copy the `claude` folder to `~/.claude/skills/prd-architect/`) |
| [../../dist/prd-architect.zip](../../dist/prd-architect.zip) | Claude.ai (upload in your skills settings) |
| [chatgpt.md](chatgpt.md) | A ChatGPT Project or custom GPT |
| [prompt.md](prompt.md) | Any AI, pasted into a chat |

There is also a ready-made [PRD Architect custom GPT](https://chatgpt.com/g/g-693b8b92a6f88191bac257f00fb49d57-prd-architect) you can use in ChatGPT instead.
